Le document de cadrage décrit un copilote Anthropic supposé déjà présent. Une recherche dans le dépôt et son historique Git complet récupéré depuis le dépôt distant indiqué n'a pas trouvé cette implémentation. Ne pas présenter cette logique comme disponible ni prétendre la « rebrancher » avant d'avoir trouvé son code source.

**Why:** La demande de réutilisation est explicite, mais le document décrit peut-être un état de travail antérieur qui n'a pas été poussé dans ce dépôt.

**How to apply:** Avant de planifier ou modifier le copilote réel, demander le fichier ou l'emplacement de l'ancienne version, ou un accord explicite pour une nouvelle implémentation si elle est introuvable.
