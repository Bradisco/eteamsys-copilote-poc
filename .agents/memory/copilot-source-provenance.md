Le document initial décrivait un ancien copilote Anthropic supposé déjà présent, mais une recherche dans le dépôt et son historique Git accessible ne l'a pas trouvé. Un document fourni ultérieurement a apporté le code et un point d'intégration pour créer un nouveau module Anthropic, et l'utilisateur a explicitement approuvé cette approche. L'intégration actuelle ne restaure donc pas une version historique identifiée.

**Why:** Éviter de confondre une nouvelle implémentation validée avec la récupération de l'ancien code réclamé au départ.

**How to apply:** Si une future demande porte sur l'ancien comportement exact ou sa parité, demander sa source originale plutôt que de supposer que le module actuel en est une copie fidèle.
